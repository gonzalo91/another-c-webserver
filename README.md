# another-c-webserver

Driven by a curiosity for low-level systems, I built a functional HTTP server using C. This project involved managing socket connections and parsing request headers, providing a deep dive into how data moves across the web without the help of modern frameworks. 

I skipped the file section as it started to be more repetitive and the technical things I was curious were already covered.
I plan to extend my knowledge by reading the following books:
- Compuuter System: A programmer perspective (I've always considered this book a low level abstraction of computing.)
- Crafting Interpreters (The second part, an intepreter is created with C, to see the differences in performance and implementations compared to Java)
